~~ 📡 C++ Network Packet Sniffer:
A terminal-based C++ application designed to capture, parse, and analyze network traffic. This tool provides insight into how network protocols work under the hood by inspecting IP addresses, headers, protocol types (TCP/UDP/HTTP), and packet payloads.

~~ 🌟 Key Highlights:
- **Header Parsing:** Extracts key information including Source IP, Destination IP, and Protocol IDs.
- **Payload Inspection:** Decodes and displays packet data in a readable CLI format.
- **Clean & Modular C++:** Built using structured programming for easy readability and maintenance.

~~ ✨ Key Features:
- Custom packet structure modeling
- Inspection engine for TCP/UDP/HTTP protocols
- User-friendly CLI format
